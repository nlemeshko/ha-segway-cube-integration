# Cube: подтверждённые настройки Bluetooth

Источник: конфигурация официального приложения Segway, Cube server ID 1112, пакет версии 600002200. Пакет получен по ссылке из встроенного backup_config.nb официального APK Segway-Ninebot 6.10.12. Основные параметры дополнительно сопоставлены с дампом станции владельца.

| Управление | Регистр MCU | Поле / значения |
|---|---|---|
| Выход AC | 0xC0 | маска 0x0002 |
| Выход DC | 0xC0 | маска 0x0001 |
| R-Drive | 0xC1 | маска 0x0004 |
| UPS | 0xC1 | маска 0x0002 |
| Звук кнопок | 0xC1 | маска 0x0008 |
| Вентилятор | 0xC1 | 0x0010: активное охлаждение; 0: тихий |
| Мощность зарядки | 0xD0 | значения в W; набор 200–1100 + 1250 либо 200–1500 + 1650, обычный шаг 100 |
| Отключение станции | 0xD3 | 0, 15, 30, 60, 120, 360, 720, 1440 минут |
| Отключение AC | 0xD4 | тот же набор минут |
| Отключение DC | 0xD5 | тот же набор минут |
| Таймер экрана | 0xDC | 0, 1, 5, 15, 30 минут |
| Частота AC | 0xD2 | 50 или 60 Hz, только при поддержке моделью |

0 означает отсутствие автоматического выключения для таймеров. Регистры читаются командой 0x01 с ответом 0x04, запись без отдельного ACK выполняется командой 0x03; результат подтверждается чтением.

Возможности в rFunSupBool (0x2B): маска 0x0300 определяет зарядный вариант: 0x0100 = 1250 W, 0x0200 = 1650 W. Маски таймеров AC/DC/станции/экрана: 0x0800 / 0x1000 / 0x2000 / 0x4000. Бит 0x0001 разрешает настройку частоты.

В дампе тестовой станции rFunSupBool = 0xFEEE: заявлен вариант зарядки до 1650 W и все четыре таймера, смена частоты не объявлена. Текущее чтение частоты 50 Hz не означает разрешение её менять.

Для битовых настроек перед записью выполняется свежее чтение в той же BLE-сессии. Новое слово: `(current & ~mask) | desired_bits`. Другие, в том числе неизвестные, биты сохраняются. Команды записи не повторяются при задержке применения: повторяются только чтения подтверждения.

Исходники приложения, его библиотек, файлы шифрования и секретный Bluetooth-ключ владельца не включаются в распространяемый компонент; в коде использованы только сведения об интерфейсе для совместимости.
